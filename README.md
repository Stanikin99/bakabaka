# проект Homeworkpoetry

## Описание проекта.

# Проект Homeworkpoetry включает в себя полезные функции, такие как:

```
1 Маскировка и возвращение строк и данных банковский карт
2 Сортировка словарей по дате (если имеется дата) и возвращение словарей с определенным значением.
Данный проект предназначен для облегчения работы с данными банковских карт, сортировкой списков по указанному значению
и выводом в новые списки по возрастанию (по дате)
```

## Установка


1. Установите необходимые программы:
```
Python - https://www.python.org/
PyCharm - https://www.jetbrains.com/pycharm/
Poetry - https://python-poetry.org/ и перейдите в раздел Documentation → Introduction → Installation → With the official installer.
Git - https://python-poetry.org/ и перейдите в раздел Documentation → Introduction → Installation → With the official installer.
```



2. Установите зависимости:

```
pip install -r requirements.txt
poetry add --group lint mypy
poetry add --group lint black
poetry add --group lint isort
```

3. Создание необходимых файлов:

```
файл .gitignore, где будут храниться исключения, которые не дожны затрагивать код
скачать их можно по ссылке https://github.com/github/gitignore/blob/main/Python.gitignore
после скачивания копируем в файл .gitignore
```
4. Клонируйте репозиторий:
   
```
git clone https://github.com/Stanikin99/bakabaka.git
```

## Использование:

```
1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. Создайте новую запись в блоге или оставьте комментарий к существующей.
```
