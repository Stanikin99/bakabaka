# проект Homeworkpoetry

```
1 - функция, которая принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание) и возвращает новый список, отсортированный по дате# - функция,  которая принимает список словарей и опционально значение для ключа state

2 Функция возвращает новый список словарей, содержащий только те словари, у которых ключ
```

## Установка
1. Клонируйте репозиторий:
``'
git clone https://github.com/Stanikin99/bakabaka.git
``'
2. Установите зависимости:
```
pip install -r requirements.txt
```
4. Запустите локальный сервер:
```
python manage.py runserver
```
## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. Создайте новую запись в блоге или оставьте комментарий к существующей.
